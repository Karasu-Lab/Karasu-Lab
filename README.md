# Karasu Lab

This is my website workdirectory managed by pnpm.

# Features

- [x] Base authentication
- [x] Scoped API Key OAuth
- [x] Single sign-on (SAML 2.0 / OIDC) via sso.karasu256.com

## How to use

### Install dependencies

```
pnpm install
```

or

```
pnpm i
```

### Build

```
pnpm build
```
